# mametisiki

大阪公立大学専用 豆知識サイト 要件定義書

1. 背景

大阪公立大学に関する豆知識をまとめた既存のTwitterアカウントの情報を、より見やすく、検索しやすい形で提供するため、Webサイトを構築する。

学生や新入生が大学生活をより豊かに、楽しく過ごせるような情報提供を目指す。

2. プロジェクト概要

プロジェクト名：大阪公立大学 豆知識サイト

4. システム要件



データベース記事データ、タグ情報、いいね！情報などを格納するデータベースが必要。

MySQLなどが利用可能。

検索機能記事タイトル、本文、ハッシュタグを対象とした全文検索機能を実装。

トレンド機能いいね！数を元に、トレンド記事を自動的に表示する機能。

集計期間の設定 (例：過去24時間、過去7日間、過去30日間)

タグ検索機能ハッシュタグをクリックすることで、該当するタグの記事一覧を表示する機能。

レスポンシブデザインPC、スマートフォン、タブレットなど、様々なデバイスに対応した表示。

（広告配信システムGoogle AdSenseなどの広告配信システムとの連携機能。）

5. 技術要件

プログラミング言語：PHP, JavaScriptなど

フレームワーク：Laravel, Reactなど (CMSの選定により変更)

サーバーサイド：Apache, Nginxなど

フロントエンド：HTML, CSS, JavaScript

6. インフラ要件

サーバー：クラウドサーバー (AWS, GCP, Azureなど) またはレンタルサーバー

ドメイン：独自ドメインの取得

SSL証明書：サイトのセキュリティ確保のため必須

7. セキュリティ要件

脆弱性対策：XSS、SQLインジェクションなどの対策を施す。

アクセス制限：管理画面へのアクセス制限、不正アクセス防止対策。

バックアップ：データの定期的なバックアップ。

8. リリース要件

リリース前にテスト環境で動作確認を実施。

サイト公開前にドメイン設定、SSL証明書設定などを完了。

9. 運用保守

記事の定期的な更新。

システムのメンテナンス、セキュリティアップデート。

アクセス状況の監視、分析。

広告掲載状況の管理
